# How to Add a Script Tag to a WordPress Website Page

This guide explains how to copy and paste a &lt;script&gt; tag into a specific page on your WordPress website. Follow these steps carefully to ensure the script works correctly.

## Prerequisites
- You have a &lt;script&gt; tag copied from our site.
- You have access to your WordPress admin account.

## Step-by-Step Instructions

1. **Log in to WordPress**  
   Open your browser, go to your site's admin URL (e.g., yoursite.com/wp-admin), and sign in.

2. **Navigate to the Page Editor**  
   In the WordPress dashboard, click **Pages** > **All Pages** in the left menu. Find the page where you want to add the script.

3. **Edit the Page**  
   Hover over the page title and click **Edit**, or click **Add New** to create a new page.

4. **Switch to Text/HTML Mode**  
   - If using the Block Editor (Gutenberg), add a **Custom HTML** block where you want the script.  
   - If using the Classic Editor, switch to the **Text** tab (not Visual).

5. **Paste the Script Tag**  
   Paste the copied &lt;script&gt; tag into the Custom HTML block or the Text editor at the desired location.

6. **Save or Update the Page**  
   Click **Publish** (for new pages) or **Update** (for existing pages) to save your changes.

7. **Check the Live Page**  
   Visit the page on your live site to confirm the script is working.

## Notes
- Ensure the &lt;script&gt; tag is pasted exactly as provided, without modifications.  
- If the script doesn’t work, verify you used the Custom HTML block or Text mode, and the page is published.  
- For scripts that need to be in the <head> or footer, contact our support for alternative methods.  
- For issues, contact our support team or WordPress documentation.
