# How to Add a Script Tag to a Weebly Website Page

This guide explains how to copy and paste a &lt;script&gt; tag into a specific page on your Weebly website. Follow these steps carefully to ensure the script works correctly.

## Prerequisites
- You have a &lt;script&gt; tag copied from our site.
- You have access to your Weebly account.

## Step-by-Step Instructions

1. **Log in to Weebly**  
   Open your browser, go to [weebly.com](https://www.weebly.com), and sign in to your account.

2. **Open the Site Editor**  
   From your Weebly dashboard, select the website you want to edit and click **Edit Site**.

3. **Navigate to the Page**  
   In the editor, use the **Pages** tab (top menu) to select the specific page where you want to add the script.

4. **Add an Embed Code Element**  
   - In the page editor, drag the **Embed Code** element from the left sidebar onto the page where you want the script to appear.  
   - Click the embedded area to edit it.

5. **Paste the Script Tag**  
   In the Embed Code box, paste the copied &lt;script&gt; tag. Click outside the box to save.

6. **Save Changes**  
   Click **Save** in the editor to confirm your changes.

7. **Publish Your Site**  
   Click **Publish** (top-right corner) to make your changes live. The script will now run on the selected page.

## Notes
- Ensure the &lt;script&gt; tag is pasted exactly as provided, without modifications.  
- If the script doesn’t work, ensure it’s in an Embed Code element and the page is published.  
- For scripts that need to be in the <head> or footer, contact our support for alternative methods.  
- For issues, contact our support team or Weebly Help Center.
