Speech-to-Text Test (iOS WebView)

Type or speak – this tests microphone permission & Web Speech API inside a WKWebView.


How to test permission:
1. Tap “Start Listening” → iOS should show a microphone permission prompt the first time.
2. If you allow, the button turns red and listening starts.
3. Speak → text appears in the box (interim in real-time, final when pause detected).
4. Tap again to stop (last partial phrase is discarded – matches common iOS behavior).

Notes for WKWebView:
• Page must be served over HTTPS or localhost (file:// may block permission).
• The WKWebView must have mediaCapture allowed in its configuration.
• iOS only supports webkitSpeechRecognition (added automatically below).
